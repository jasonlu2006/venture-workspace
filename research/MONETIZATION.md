# MONETIZATION PLAN — Release Notes AI
Written 2026-08-22. Current state: free product live, $0 revenue, Stripe path
coded but no key. Principle: keep the self-hosted core free forever (it's the
marketing engine); monetize convenience, scale, and team features.

## TIER LADDER (build in this order)

### Tier 0 — Free / Self-hosted (LIVE — the funnel)
Everything today: CLI, web app, widget, GitHub Action. MIT.
Purpose: stars → users → word of mouth → upgrade triggers below.

### Tier 1 — Pro Hosted ($9/mo per workspace) — BUILD FIRST
Target: solo devs & small SaaS teams who don't want to run a server.
Features that justify paying (all recurring-value, low infra):
- Scheduled auto-publish: cron checks each repo daily, publishes notes on new tags
- Custom domain + white-label widget (no "Generated by RNA" footer)
- Email digest: "What's New" sent to your user list on each release
- Version-to-version diff view
- Private repo support (needs their GH token stored encrypted)
Infra cost per user: ~$0 (Render free/one dyno serves many; SQLite fine).
Breakeven at ~1 user. Target: 25 paid = $225 MRR in first 90 days.
Requires: Stripe account (user action), webhook for entitlements, auth
(GitHub OAuth login — one afternoon of work).

### Tier 2 — Team ($29/mo) — after Pro has ~10 customers
Everything in Pro, plus:
- Multi-repo workspaces with unified changelog page
- Draft-review workflow: AI generates → teammate approves → publish
  (this is the killer feature for teams; release notes are a trust artifact)
- Slack/Discord announce integration ("#releases channel ping")
- Analytics: which features users actually read about
Seats-based pricing aligns value with company size.

### Tier 3 — Business ($99+/mo) — opportunistic, don't build yet
- SSO/SAML (only build when a customer asks and will pay upfront)
- On-prem Docker image with license key (for security-conscious orgs)
- API access for CI/CD pipelines at volume
- Priority support + custom rewriting rules

## OTHER REVENUE STREAMS (secondary)

### GitHub Marketplace / Sponsorships
- GitHub Sponsors one-time "Support this project" — passive, zero effort
- GitHub App listing (marketplace): sell the Action as verified app later;
  marketplace takes 0% on free, standard fees on paid apps

### Usage-based add-on: LLM rewriting credits
Free tier uses offline heuristics. Optional: bring-your-own-key (free) OR
buy 500 LLM-polished rewrites for $5. Margin is high since costs are fractions
of a cent per rewrite. Only worth it if heuristics get frequent complaints.

### Template/preset marketplace (later, network effect)
Community-submitted rewrite-rule packs per language/ecosystem (Rust crates,
Go modules, monorepos). Free but drives adoption; maybe paid premium packs.

## PRICING PSYCHOLOGY NOTES
- $9 not $10 (under-cutting Beamer's $49 anchor makes "cheap" the story)
- Annual = 10x monthly price (2 months free)
- Never paywall: privacy (self-host), core generation quality, or the widget
- Public roadmap: "X is free forever" builds trust with OSS audience

## METRICS TO TRACK (from launch day)
- Waitlist signups (waitlist.db) → target 100 in month 1
- Demo generations/day (add lightweight counter) → engagement signal
- GitHub stars → virality proxy
- Free→paid conversion assumption: 2-4% of active self-hosters eventually
